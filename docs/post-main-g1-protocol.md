# G1 多模态可学习评分：本地实现规格

原文说明用可学习变换计算多模态评分，但这不足以唯一确定其监督和梯度路径。本地采用明确的两阶段适配，不把随机变换后的 Top-K 称为训练好的检索器，也不声称复现原文未公开的训练细节。

## 固定结构与训练路径

1. 评分器预训练：固定原始 128 维内容向量，使用共享 `128→64→32` ReLU MLP 对目标和历史投影，输出 L2 归一化后点积。点积除以固定温度 0.1，经 mask、softmax 后加权原始内容历史向量；与目标内容拼接，经 `256→64→1` 点击预测头，用训练曝光的 BCE 训练一轮。
2. 下游检索：只加载已训练的投影网络并冻结；按变换后点积选 Top-50。下游仍使用原始内容余弦的 SA-TA 和 SimTier，公共 ID 主干不变。预训练点击头不进入下游模型。
3. 对照：原始内容余弦检索，使用相同下游初始化、模型与训练协议。预训练预算单列，不能称两者总训练成本相同。

两阶段都固定训练集、L=1000、batch=256、种子 42/2026/3407。评分器用 AdamW、学习率 0.001、weight decay=0、一轮，不用验证集挑选预训练轮数。下游维持共同 SparseAdam/AdamW 协议。内容缺失与 padding 规则和既有检索一致。

选择两阶段是为了让 GSU 的投影参数得到真实训练，同时保持最终 ESU 结构及输入语义不变。该辅助 CTR 目标是本地适配；结果只能说明这一训练方案，不能推广为所有可学习多模态评分。

## 当前状态

评分器和冻结检索模块已实现，通过“投影参数收到非零有限梯度”和“下游投影保持冻结、ESU 仍训练”的测试。评分器训练入口已实现并进入资源探针；下游检查点传递与完整效果实验尚未完成，不能算 G1 已完成。
