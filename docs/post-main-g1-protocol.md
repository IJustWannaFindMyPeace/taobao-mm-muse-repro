# G1 多模态可学习评分：本地实现规格

> 文档性质：阶段记录／历史协议。本文中的规模、配置、验证结果及待办状态属于记录时点；当前结果以[主测试](final-test-results.md)、[补充测试](supplementary-test-results.md)和[覆盖说明](current-reproduction-status.md)为准。

> 本文保留原验证阶段分析；对应最终下游模型的追加测试已归档，参见[统一追加测试结果](supplementary-test-results.md)。过程诊断不自动变成测试证据。


原文说明用可学习变换计算多模态评分，但这不足以唯一确定其监督和梯度路径。本地采用明确的两阶段适配，不把随机变换后的 Top-K 称为训练好的检索器，也不声称复现原文未公开的训练细节。

## 固定结构与训练路径

1. 评分器预训练：固定原始 128 维多模态向量，使用共享 `128→64→32` ReLU MLP 对目标和历史投影，输出 L2 归一化后点积。点积除以固定温度 0.1，经 mask、softmax 后加权原始历史多模态向量；与目标多模态表示拼接，经 `256→64→1` 点击率预测头，用训练曝光的 BCE 训练一轮。
2. 下游检索：只加载已训练的投影网络并冻结；按变换后点积选 Top-50。下游仍使用原始多模态余弦的 SA-TA 和 SimTier，公共 ID 主干不变。预训练点击头不进入下游模型。
3. 对照：原始多模态余弦检索，使用相同下游初始化、模型与训练协议。预训练预算单列，不能称两者总训练成本相同。

两阶段都固定训练集、L=1000、batch=256、种子 42/2026/3407。评分器用 AdamW、学习率 0.001、weight decay=0、一轮，不用验证集挑选预训练轮数。下游维持共同 SparseAdam/AdamW 协议。多模态表示缺失与 padding 规则和既有检索一致。

选择两阶段是为了让 GSU 的投影参数得到真实训练，同时保持最终 ESU 结构及输入语义不变。该辅助 CTR 目标是本地适配；结果只能说明这一训练方案，不能推广为所有可学习多模态评分。

## 资源验证与执行

两阶段均完成 100 步训练及完整验证集预测检查。评分器投影参数已更新；下游投影参数保持逐元素不变，公共推荐参数正常更新；两阶段保存、重载后的预测最大误差均为 0。评分器训练峰值显存约 0.69 GiB，下游约 8.15 GiB。探针仅验证工程可行性，不作为完整效果证据。

`run_g1_extension.py` 固定执行三个种子的评分器预训练与下游训练，共六次完整训练。它核验配置、源码、数据清单、预测行与标签，完整下游训练拒绝加载探针检查点。预训练及下游各使用 3,052,475 条训练曝光、一轮 11,924 步；验证集为 768,773 条曝光。

对照复用 G3 扩展中三个种子的多模态余弦模型：共同下游超参数一致，验证预测已与主实验 R4-L1000 逐元素对齐。运行计划记录复用报告与预测文件的 SHA-256，每个种子分别进行用户级配对 bootstrap。额外评分器预训练的耗时与显存单列。

依据探针吞吐，六次训练及验证预计约 4.22 小时，另有配对统计和结果整理。预计超过六小时或触发既有资源限制时停止复核，不自动调整 batch 或数据规模。

完整实验和三种子配对统计已完成，见[结果与局限](post-main-g1-results.md)。该补充研究只使用验证集，不产生新的盲测证据。
