# 适配基线：统一测试集比较

全部使用同一923,211条测试曝光，三个种子取算术均值。主实验与后续追加评估的来源阶段分别记录，不能合称一次新的盲测。

|模型|历史预算与聚合|AUC|GAUC|LogLoss|
|---|---|---:|---:|---:|
|DIN 局部激活适配|短历史50；无长历史检索|0.601594|0.573718|0.392569|
|短历史点积对照|短历史50；无长历史检索|0.601706|0.573466|0.392574|
|SIM-hard 类目检索适配|L1000→K50；增强 ESU|0.612869|0.589523|0.390583|
|SIM-soft ID检索适配|L1000→K50；增强 ESU|0.613921|0.590532|0.390450|
|TWIN 一致评分适配|L1000；4头各50，至多200个位置|0.611542|0.580828|0.390914|
|TWIN 多模态检索对照|L1000；4头共用多模态Top50|0.618782|0.596396|0.389615|
|MISS 双路分离适配|L1000；ID25＋多模态表示25，可能重叠|0.606536|0.576023|0.391837|
|MISS 多模态表示双路对照|L1000；多模态Top50分成两路各25|0.605731|0.576726|0.391946|
|MUSE 完整适配|L1000→K50；SimTier＋SA-TA|0.618785|0.595488|0.389512|

不同结构、参数量和候选历史预算同时存在差异；均值用于比较总体效果，配对区间用于判断具体差值的统计证据。原工业模型细节并未完整复现，机制解释应优先参考各方法内部的配对控制。

测试耗时不列入性能比较。本次存在并行外部负载，无法把运行记录解释为受控算法效率。
