# 四头一致性检索：固定补充协议

本实验检验 TWIN 启发的四头一致性检索在公共 CTR 主干中的表现。它是主测试已查看后的验证集扩展，不是原始工业 TWIN 完整复现，也不改写原冻结主表。

## 两个固定模型

|设置|一致性检索适配|内容检索对照|
|---|---|---|
|检索|每个头使用其可学习 query/key 分数选择历史|内容余弦选择历史，四个头共用所选位置|
|聚合|同一 query/key 参数重新计算所选分数，softmax 加权投影后的 ID 值|完全相同的四头 ID 聚合|
|头数与维度|4 头，每头 8 维，拼接后投影到 32 维|相同|
|SimTier|对所选历史位置的并集计数|相同|
|公共部分|10 个 ID 字段、近期 50 条行为分支、相同预测塔|相同|

每个头 K=50，两模型每例最多处理 200 个“头—位置”组合。一致性模型去重后最多覆盖 200 个历史位置，内容对照最多覆盖 50 个。这是明确的多头检索设计差异，**不是相同去重覆盖预算**。训练报告同时给出实际处理数和去重覆盖数；不能将本实验与原单路 K=50 主表称为等预算比较。K 的多头分配是本地选择，不声称由论文唯一确定。

所有头共享底层商品与类目 embedding，拥有各自的 query/key/value 投影切片。索引选择无梯度；所选 ID 重新查表，并通过同一评分参数进行可微聚合。不同头重复选中同一历史位置时，SimTier 只计一次；同一商品在不同历史位置出现仍分别计数。

## 数据、训练和边界

沿用 5% 用户队列，L=1000，batch=256，单轮，种子 42/2026/3407。SparseAdam 与 AdamW 学习率均为 0.001；两模型在同一种子下的初始参数和样本顺序一致。先各进行 100 步资源探针，再启动六次完整训练；探针分数不用于调参或效果比较。

原始 TWIN 的工业交叉行为特征、缓存系统和完整特征集合未实现；这里只使用已建模的商品与类目固有特征。根据 MUSE 的 CTR 比较思路加入 SimTier，但并集计数规则和注意力宽度是公开的本地适配。内容缺失沿用已有策略；ID 检索与内容检索的可用候选可能不同，这也是两种检索方式的实际差异。

主比较为各种子内“一致性检索 − 内容检索”的完整验证指标及用户级配对 GAUC 区间。它比较两种检索方案，不能单独把差值归因于参数共享；后者还需要不同训练方式的独立控制。不得按验证结果改变 K、头数或学习率后仅保留胜出设置。
