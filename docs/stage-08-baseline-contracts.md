# 阶段 8：独立基线的检索契约与规模约束

> 文档性质：阶段记录／历史协议。本文中的规模、配置、验证结果及待办状态属于记录时点；当前结果以[主测试](final-test-results.md)、[补充测试](supplementary-test-results.md)和[覆盖说明](current-reproduction-status.md)为准。

## 版本区分

[MUSE §7.1.2](https://arxiv.org/html/2512.07216v1#S7.SS1.SSS2) 的 SIM-hard 与 SIM-soft 采用 MUSE 的 SA-TA + SimTier ESU。它们不能与原始 SIM 完整模型混称。本地参考归档中的 `trainer.py`、`model/muse.py` 与 `config/sim_*.json` 也采用共享增强 ESU 的路径。DIN 分支屏蔽长历史输出；短历史仍由公共模块处理。原始 DIN 的局部激活网络版本如实现，须另标，不能把现有点积注意力命名为原始 DIN 完整复现。

## 检索契约

本轮新增独立 `baseline_retrieval.py`，未接入训练入口，不能据此宣称基线完成。

- 类目选择仅比较已知类目 ID（编码大于 1）；未知类目之间不视作同类。按最近行为选取，同一商品多次出现按行为保留。匹配不足 K 的位置无效，不跨类目补齐；未知目标或无匹配返回空有效集合。这是显式本地策略。
- G-ID 使用有效且有非零向量的已知商品 ID；零余弦仍有效，负余弦不被错误排除，并列优先最近。未知/零向量目标回退最近有效 ID 行为，已知目标排除未知/零向量候选。
- Top-K 选择 no-grad，但 ESU 必须在该上下文外重新查共享 embedding。测试验证检索索引无梯度，选中商品与目标 embedding 仍可从后续损失获得梯度。该测试证明工程梯度路径，并不保证端到端检索最优或等价于原始 SIM 的训练目标。
- 分组统计、语义相似度与 ID 行为必须使用同一选中索引和 mask，不能混合不同历史集合。

全套现有与新增单元测试共 21 项通过，涵盖未知类目、重复行为、候选不足、零/负分数、并列、缺失回退和共享 embedding 梯度。尚无新增基线的真实数据训练、资源或效果报告。

## 规模决策依据

当前 5% 存储所有可训练字段词表共 43,152,867 行，embedding 维度 16。以 FP32 权重和 SparseAdam 两份稠密状态估算，单是这些数组就需约 7.72 GiB；不含中间激活、稀疏梯度、CUDA 库与其他参数。已有完整训练峰值约 7.8 GiB 与这一量级相符。

因此限制主要来自训练词表，而不只是 batch 或曝光行数。将用户比例从 5% 扩到 10% 不代表词表线性翻倍，必须统计新子集真实唯一 ID；减小 batch 也不能消除 embedding 和优化器状态。当前 5% 是候选主规模，不是已确认的最大规模。

下一步先完成基线整模型、有效梯度与真实批次资源验证，再对候选更大用户子集做只读/流式词表计数与内存预算。只有最耗资源模型留有显存/系统内存余量且整套三种子预算可接受时才扩容。更改 embedding 维度、哈希词表或优化器状态放置会改变实验协议，不能当作无影响的省显存选项。

本阶段无新 GPU 长任务，未评估保留测试集。

后续整模型接入与真实资源验证已完成，当前进展见[阶段 9](stage-09-baseline-resource-gate.md)。上述“待接入”描述保留本阶段检查时点，不作为最新状态。
