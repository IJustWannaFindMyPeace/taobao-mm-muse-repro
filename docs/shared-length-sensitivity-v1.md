# 历史长度敏感性：固定检索数量

共同协议 seed=42 补 L50、L500，分别使用内容检索 + 普通注意力、内容检索 + 语义注意力 + 相似度统计。K=50、短历史长度=50、数据及其他训练参数不变。结合已有同种子 L200/L1000，形成四点诊断曲线。

预先比较各方法相邻长度 L50→L200、L200→L500、L500→L1000，分别报告 GAUC/AUC/LogLoss 与按用户配对区间；不根据最优点重新挑选核心模型。L50 时有效历史不足或恰好等于 K，主要不再有压缩候选集合的空间，解释时单列。长度增加改变训练输入，也可能改变短历史用户上的预测，因为模型参数共同训练。

四组已启动，完成后审计配置仅改变 L、完整预测与公共源码。单种子敏感性不能代替训练随机性，所得曲线不外推超过公开 1000 条历史的范围。未评估保留测试集。
