# 历史长度敏感性：固定检索数量

共同协议 seed=42 补 L50、L500，分别使用内容检索 + 普通注意力、内容检索 + 语义注意力 + 相似度统计。K=50、短历史长度=50、数据及其他训练参数不变。结合已有同种子 L200/L1000，形成四点诊断曲线。

预先比较各方法相邻长度 L50→L200、L200→L500、L500→L1000，分别报告 GAUC/AUC/LogLoss 与按用户配对区间；不根据最优点重新挑选核心模型。L50 时有效历史不足或恰好等于 K，主要不再有压缩候选集合的空间，解释时单列。长度增加改变训练输入，也可能改变短历史用户上的预测，因为模型参数共同训练。

四组训练及八组相关预测审计均完成，确认同系列配置仅改变 L、完整预测与公共源码一致。单种子敏感性不能代替训练随机性，所得曲线不外推超过公开 1000 条历史的范围。未评估保留测试集。


## 单种子结果

|聚合方式与长度变化|GAUC 差|95% 用户配对区间|
|---|---:|---|
|普通注意力 50→200|-0.000886|[-0.002142, 0.000416]|
|普通注意力 200→500|+0.001940|[0.000517, 0.003395]|
|普通注意力 500→1000|+0.001017|[-0.000280, 0.002352]|
|完整组合 50→200|+0.002004|[0.000455, 0.003565]|
|完整组合 200→500|+0.002919|[0.001476, 0.004454]|
|完整组合 500→1000|-0.000235|[-0.001560, 0.001063]|

完整组合从 50→200、200→500 的区间为正；500→1000 的区间跨零，不能认定 500 最优或二者等效。普通注意力仅 200→500 的相邻比较区间为正。该四点诊断与已有 200→1000 三种子收益相容，不要求每个相邻区间均有明确增益。

本次核验八组完整验证预测的源行、用户、标签及指标，检查步数、检查点存在性、长度之外的配置和实现摘要。六次配对区间各用 2000 次用户 bootstrap，未作多重校正，只条件于本种子模型和验证人群。仍保留 L200 核心、L1000 长历史主对照，不根据本曲线重新选择主模型。
