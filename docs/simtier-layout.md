# SimTier 统计布局与检查点兼容性

自2026-10-12起，统计输出由22维清理为21维，移除永远为零的索引21及其缩放参数、接入层对应列。分桶公式不变：`ceil(10*s)+10`，相似度限制在[-1,1]，索引为0～20；索引0接收端点-1，其余20个位置为宽度0.1的右闭区间。

原始计数仍经过 `log1p` 与逐位置可学习缩放，接入层由22→128改为21→128。每个使用该路径的模型减少129个无效参数。TWIN扩展同步使用相同布局。

`load_state_dict` 支持旧22维模型权重：自动保留缩放向量前21项及接入矩阵前21列，严格检查其他不匹配。检查点原文件不被改写。兼容处理针对模型权重，不提供旧优化器状态的形状迁移。

旧布局等价性测试覆盖语义注意力开启/关闭、仅统计路径、缺失目标和全空历史；完整单元测试47项通过，预测使用浮点容差核验。历史测试指标仍对应原归档实现，未重新训练或重算。矩阵宽度变化可能引入浮点舍入差异，不能承诺逐位一致；新训练的随机数消耗也可能不同，不能将新运行冒充原训练轨迹。

严格回放历史实验时应使用冻结清单对应代码版本；源码哈希变化后，不应修改既有冻结摘要以绕过一致性检查。
