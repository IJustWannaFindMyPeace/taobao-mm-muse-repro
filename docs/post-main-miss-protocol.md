# MISS 双路 CTR 适配：固定协议

> 文档性质：阶段记录／历史协议。本文中的规模、配置、验证结果及待办状态属于记录时点；当前结果以[主测试](final-test-results.md)、[补充测试](supplementary-test-results.md)和[覆盖说明](current-reproduction-status.md)为准。

> 本文保留原验证阶段分析；对应最终下游模型的追加测试已归档，参见[统一追加测试结果](supplementary-test-results.md)。过程诊断不自动变成测试证据。


目的：在既定公共主干上检验协同与多模态表示双路检索是否改善排序。保留两路子序列与 ID-only 精细聚合，不实现原始 MISS 索引树、节点负采样、多任务 MMoE 或在线召回系统。因原文存在参数共享歧义，本地结构选择与敏感性分析分开报告。

## 三种固定配置

|配置|协同槽位 25 条|多模态表示槽位 25 条|两路聚合参数|
|---|---|---|---|
|主模型：双路检索|可学习 ID query/key 评分 Top-25|多模态余弦 Top-25|分离|
|主对照：多模态检索|多模态表示 Top-50 的第 26–50 条|多模态表示 Top-50 的第 1–25 条|分离|
|敏感性：共享聚合|与主模型相同的检索规则|与主模型相同的检索规则|共享 query/key/value|

三种配置均使用两个 32 维聚合向量，拼接后线性映射到公共主干的 32 维长期兴趣输入。query/key/value 为无偏置投影，评分除以维度平方根，mask 后 softmax 加权 ID 值；不使用 SimTier 或 SA-TA。短历史分支、ID 字段和预测塔保持共同设置。

主对照的分段规则是本地设计，用于保留相同双路参数容量和总位置预算。双路主模型可能重复选中同一历史位置，多模态表示分段对照不会。报告实际路内处理数、去重覆盖数和交集，不能把总预算相同理解为去重覆盖相同。同一商品的不同历史记录不去重。每路不足 25 条时保留有效位置并 mask，不从另一条路自动补齐。

协同检索与其聚合使用同一评分参数。Top-K 索引无梯度，所选历史重新查表、重新评分以保留梯度。多模态向量仅影响选取位置，不进入 ESU 的值向量或统计特征。多模态表示缺失沿用已有检索回退规则。

## 训练与判读

固定 5% 用户队列、L=1000、总 K=50、batch=256、单轮，种子 42/2026/3407，共九次训练。两类优化器与学习率沿用公共协议。先对每种配置进行 100 步资源探针；探针指标不用于调参。六小时为启动整批前的估算时间检查，不是单卡可行性的硬上限；超过时先分析吞吐，不自动改变模型或 batch。

主比较是双路分离参数模型减去多模态表示分段对照；敏感性比较是共享参数减去分离参数的双路模型。共享实验同时改变参数约束和参数量，不能解释为纯优化收益。所有配置与比较在完整训练前固定，三种子全部报告，不依据分数选择论文实现口径。

这属于主测试已查看后的验证集扩展，不修改冻结主表。公开数据使用商品与类目特征代替原始索引树节点表示；研究结论局限于当前 CTR 适配。[来源歧义记录](post-main-retrieval-source-audit.md)说明了论文与本地选择的区别。
