# TWIN 与 MISS：来源歧义和实施约束

本记录区分论文事实与本地设计，服务于主实验结束后的补充阶段。此记录形成时尚无新增结果；当前适配结果见 [TWIN](post-main-twin-results.md) 和 [MISS](post-main-miss-results.md)。不能将既有 ID 余弦或余弦融合模型重命名为 TWIN/MISS。

## 已核实的机制

[TWIN §3.3](https://arxiv.org/html/2302.02352v2)使用相同相关性评分完成检索和精细聚合，包含商品固有特征投影、交叉行为特征偏置，以及四头注意力。公开数据不能直接提供其工业交叉特征与缓存系统。共享评分可以检验，但缺失特征和缓存收益不能声称复现。

[MISS §4.2](https://arxiv.org/html/2508.14515v1)保留协同与内容两路子序列，分别进行 ID 特征聚合。其 ESU 开头描述参数共享，但式 (13)–(14) 后又明确描述与协同子序列不共享参数；因此，跨两路共享不能作为已确定事实。协同路径的检索评分复用与两路之间的共享是两个不同问题。完整索引树与多任务召回不属于当前 CTR 补充范围。

[MUSE §7.1](https://arxiv.org/html/2512.07216v1)比较的是共同 CTR 主干中的适配版本：TWIN 保留特殊注意力并增加 SimTier，MISS 保留 ID-only 聚合；文中统一描述检索 50 条历史，但不足以唯一确定多头及双路的预算分配。这些细节必须公开记录，不能依结果倒推实现。

## 本地实施约束

|问题|实施要求|验证方式|
|---|---|---|
|检索与聚合一致性|两阶段调用同一评分参数；Top-K 索引无梯度，选中行为的评分需重新计算并保留梯度|对选中位置逐项比较分数；检查 query/key 参数更新|
|四头检索预算|明确 K 是每头预算还是总预算，报告处理位置数与去重后覆盖数|不能把每头 50、四头最多覆盖 200，与单路总计 50 当作等预算消融|
|双路预算|主对照固定总处理预算；每路预算和不足时行为写入配置|统计每路有效数、交集和去重覆盖；禁止隐式扩大 K|
|两路重合|保留两路表示的语义；同一历史位置出现在不同路不等于两次真实行为|分别记录路内位置与跨路交集；统计特征不得意外重复计数|
|MISS 参数歧义|先固定共享或分离口径，明确为本地选择；另一口径若运行，应作为敏感性分析单列|代码检查参数对象身份和梯度，禁止按验证分数择优后称为论文结构|
|内容缺失与 padding|沿用既定缺失内容策略；无效位置不参与排序、softmax 或统计|全空、缺失目标内容、有效历史少于 K、重复商品和同分测试|
|数据与训练|既定 5% 队列、三个种子、batch=256、单轮及共同优化器|配置与数据指纹；实测资源探针通过后再启动训练|

## 可支持的结论

实现优先回答两个机制问题：学习到的同一评分用于两阶段，是否优于不一致的检索标准；保留协同与内容两路，是否优于单路内容检索。每项需要相同聚合结构下的对应控制，不能直接用整个 TWIN 与整个 MUSE 的差值归因于某一个模块。

单头公共主干版本只能标作一致性检索机制对照，不能替代四头 TWIN。双路 CTR 适配只能支持兴趣建模比较，不能支持原始 MISS 索引树召回率结论。原冻结 54 模型结果与后续补充结果持续分开报告。
