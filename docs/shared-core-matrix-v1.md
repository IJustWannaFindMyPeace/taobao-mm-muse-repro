# 共同协议下的核心对照矩阵

> 文档性质：阶段记录／历史协议。本文中的规模、配置、验证结果及待办状态属于记录时点；当前结果以[主测试](final-test-results.md)、[补充测试](supplementary-test-results.md)和[覆盖说明](current-reproduction-status.md)为准。

本阶段从训练方案选择回到方法效果验证。两个项目采用共同 5% 用户队列、batch=256、两类学习率 0.001、单轮下游训练；首先运行 seed=42，整组审计后再扩展到 2026、3407。seed=42 全部训练及完整预测审计已完成；2026、3407 已进入串行训练及审计队列。

## 第一部分：多模态表示怎样进入推荐模型

|方法|配置索引|要回答的问题|
|---|---|---|
|ID 基线|C0|没有新增多模态分支时的参照|
|直接多模态向量融合|C2|直接引入向量是否有效|
|相似度分桶统计|C3|相似度分布是否提供有用信息|
|预训练多模态知识接入|C5|单独接入 MAKE 知识的效果|
|相似度统计 + 预训练多模态知识|C6|两类信息是否互补|
|逐行为相似度侧信息|C7|保留逐条相似度与分桶统计有何差异|

MAKE 的随机/预训练与冻结/联合训练四组策略属于后续专项矩阵，不能仅凭 C5 对 C0 将所有收益归因于预训练。

## 第二部分：如何选择和理解历史

|方法|配置索引|关键比较|
|---|---|---|
|最近 K 条 + 普通注意力|R0|近期行为参照|
|多模态检索 + 普通注意力|R1|R1 对 R0：目标相关选择|
|多模态检索 + 普通注意力 + 相似度统计|R2|R2 对 R1：统计分支|
|多模态检索 + 语义感知注意力|R3|R3 对 R1：语义注意力|
|多模态检索 + 语义注意力 + 相似度统计|R4|分别对 R2、R3：额外贡献|
|多模态检索 + 长历史统计分支|R5|对 R2：长历史 ID 注意力的额外贡献|

R5 仍保留公共 ID 和短历史分支，不是全模型 content-only。类目和 ID 检索、更多历史长度等对照后续单列。当前核心矩阵均为 L200，MUSE 的 K=50；不能把 L1000 的历史收益混入本轮模块消融。

两个项目共享数据和训练约束，但模型主干细节及相似度分桶定义不同。跨项目最佳分数不能直接解释为单变量算法升级。

## 执行与复用

入口为 `scripts/run_shared_core.py`，参数包括共享存储、多模态表示集成项目路径、同种子的MAKE 推荐预训练运行、直方图缓存和新输出目录。`--plan-only` 执行来源及配置核验并输出计划，不启动训练；正式运行保存共同协议摘要、逐模型最终配置及队列状态，串行训练，失败即停止。

seed=42 矩阵包含 12 组，11 组新训练。C6 复用已独立审计的 batch=256、两类学习率 0.001 运行：检查除名称外的完整配置、预测与报告摘要、数据清单及当前训练/模型源码摘要，记录原产物路径；没有复制、重新命名或重复训练其权重。汇总与审计时必须按计划中的复用路径读取，不能假定每项均位于新输出目录。

MAKE 推荐预训练继续使用既有单独协议，以验证 GAUC 最大、并列取最早轮的规则选择同种子检查点，并验证摘要。不同预训练预算和最终选点均保留。下游共同协议不会悄悄改变预训练 batch。

执行前核验 12 个配置共同参数及历史窗口，MUSE 现有 24 项测试通过。完成训练不等于效果审计完成；完整预测仍需对齐源行、标签和用户并重算指标，再进行预先定义的配对比较。保留测试集未评估，旧 batch=32 结果与新主表分开。


## 首个种子的审计结果

12 组均完整核对 768,773 条验证预测，源行、用户、标签与共享存储一致，重算指标一致；核对训练步数、配置计划、公共源码及多模态表示检查点/缓存一致性。配对分析采用 2000 次用户 bootstrap，以下为单种子验证证据，15 个区间未做多重比较校正。

|比较（前者减后者）|GAUC 差|95% 配对区间|
|---|---:|---|
|统计 + MAKE − 单独统计|+0.002852|[0.001121, 0.004591]|
|统计 + MAKE − 单独 MAKE|+0.001636|[0.000926, 0.002374]|
|逐行为相似度 − 统计 + MAKE|+0.001303|[-0.000511, 0.003134]|
|多模态检索 − 最近历史|-0.000566|[-0.001828, 0.000673]|
|增加统计分支|+0.016760|[0.015093, 0.018399]|
|增加语义注意力|+0.007612|[0.006385, 0.008873]|
|已有统计时再加语义注意力|+0.000245|[-0.000384, 0.000866]|
|完整组合 − 长历史统计分支|-0.000428|[-0.001571, 0.000711]|

多模态融合的统计 + MAKE 组合相对各自单项有正向 GAUC 区间。MUSE 单独增加统计或语义注意力也有正向区间；但“多模态检索相对近期选择”和“完整组合相对已有统计方案”的 GAUC 区间跨零，不能由点估计排序断言胜负或等效。

指标并不完全一致：多模态检索相对最近历史的 AUC、LogLoss 点估计更好而 GAUC 略低；直接向量融合相对 ID 基线的 GAUC 提高但 LogLoss 变差；完整组合相对长历史统计分支的 AUC、LogLoss 改善但 GAUC 略低。全部结果保留，后续以三个种子汇总检查稳定性，不要求故事线每步都提升。

[完整审计报告](../reports/shared-core-v1-seed42-audit.json)保留所有指标与比较。后续入口 `run_shared_seed_queue.py` 先检查首种子审计前置条件，依次运行 2026、3407，每个种子训练完成后自动调用 `audit_shared_core.py`，任一训练或审计失败即停止队列。尚未完成的种子不计入结果，测试集未评估。
