# G3：内容相似度与 ID 注意力融合检索

> 本文保留原验证阶段分析；对应最终下游模型的追加测试已归档，参见[统一追加测试结果](supplementary-test-results.md)。过程诊断不自动变成测试证据。


本实验补齐覆盖审计中的 G3 缺口。主对照固定为内容余弦检索，候选使用已有 SA-TA 的融合评分进行 Top-K 检索。公共 embedding、短历史分支、值投影、SimTier 和预测塔保持相同，均使用 L=1000、K=50、batch=256、单轮与三个种子。

## 评分和训练路径

候选分数为 `gamma[0] * ID_score + gamma[1] * content_cosine + gamma[2] * ID_score * content_cosine`。这里 ID_score 来自 ESU 的 query/key 投影点积，除以维度平方根；内容余弦来自固定原始向量。gamma、query、key 与 ESU 使用同一组参数，不为无梯度的 Top-K 新增独立未训练网络。

选择索引时不保留梯度，选中行为重新查 embedding 并在 ESU 中重新计算评分，通过点击损失训练共享参数。这样可以训练评分参数，但并不意味着硬 Top-K 本身可微，也不保证未选中行为直接获得检索梯度。

沿用共同初始化 `gamma=[1,0,0]`，因此候选初始由 ID 分数主导，再由训练改变融合。允许权重为负，不将其解释为概率。融合采用本地已有 SA-TA 形式，是明确的机制适配，不声称唯一还原原文未公开的实现细节。

两方法使用同一内容可用候选集合。目标内容可用时排除缺失历史内容；目标内容缺失时都退回最近有效历史。并列按近期优先、padding 不入选。SimTier 始终统计原始内容余弦，不改为融合分数分桶。

## 固定比较和准入

两个配置各三个种子，共六次训练，只评估验证集。内容对照重新运行，以核验公共实现；单元测试已确认其前向和反向与原 MUSE 模型完全一致。此轮不将旧测试结果用于选择融合权重、学习率或 K。

每种配置先运行 100 步探针并完整验证，检查参数更新、梯度、数据行、资源和检查点重载。六小时只是整批启动前的估算时间检查；超过则分析吞吐，不自动缩减 batch 或数据。完成后逐种子报告 GAUC 配对区间及 AUC、LogLoss，原冻结结果保持不变。

本实验不覆盖 G1 多模态可学习评分。G1 仍须另行定义可学习变换的监督路径，不能由本次共享 ID 评分代替。
