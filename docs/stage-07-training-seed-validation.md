# 阶段 7：固定数据上的训练随机性验证

> 文档性质：阶段记录／历史协议。本文中的规模、配置、验证结果及待办状态属于记录时点；当前结果以[主测试](final-test-results.md)、[补充测试](supplementary-test-results.md)和[覆盖说明](current-reproduction-status.md)为准。

## 目的与控制变量

单种子配对 bootstrap 反映固定预测在人群重采样下的变化，不包含随机初始化和训练顺序的影响。本阶段固定 5% 存储、全部超参数及 R0–R5 的模块定义，依次补充训练 seed 2026、3407，与已完成的 seed 42 比较。

只修改模型初始化和训练样本打乱所用的种子，不重新抽取用户或改变训练/验证划分。每组使用历史长度 200、K=50，完整训练一轮并评估完整验证集。保留测试集不用于选择种子或配置。

## 执行与产物

```powershell
python scripts/run_core_study.py --store <store-050> --output-dir <fresh-seed-directory> --seed 2026
```

入口保存六份最终配置快照，逐组串行训练并保存日志、模型、验证预测和报告。seed 2026 六组完整训练已结束，纯训练合计约 3.90 小时，验证与保存另计。每组均完整使用 3,052,475 条训练曝光与 768,773 条验证曝光，检查点重载误差为零。与 seed 42 相比，各组运行代码和数据摘要一致，超参数仅 `seed` 不同。

seed 3407 六组训练和保存预测审计均已完成。三个种子的各组源码摘要、数据版本和除训练种子以外的超参数均一致。历史长度端点的其他种子和配套 CIKM 项目的多种子实验尚未完成，不能将本队列完成视为两项目所有稳定性验证结束。

同种子 GAUC 增量的三次均值：R1−R0 为 0.001249，R2−R1 为 0.016854，R3−R1 为 0.007978，R4−R3 为 0.009475，R4−R2 为 0.000600，R2−R5 为 0.000652。这六项在三个种子中方向均为正，但幅度和每次用户 bootstrap 区间的证据强弱不同。

SimTier 和单独加入 SA-TA 的增量在三个种子中均较明确。R4 相对 R2 的平均额外收益较小，其用户区间仅在 seed 3407 中高于零；R2 相对 R5 在 seed 3407 中几乎持平。因而不能将一致排名写成所有模块都具有稳健的独立贡献。标准差描述三次训练的离散程度，不是均值的置信区间，也不证明对其他数据人群的泛化。

可复现汇总入口为 `scripts/summarize_training_seeds.py`，输入三份运行目录和各自审计摘要；入口校验报告摘要及跨种子的代码、数据和配置一致性后计算结果。

三种子完成后，对每个模型报告 AUC、GAUC、LogLoss 的各次结果、均值和样本标准差，并报告同种子内关键消融增量及其方向。不得挑选最佳种子作为总体效果，也不把三个训练种子当作数十万独立样本。三个种子仍不足以证明普遍稳定性，需保留这一限制。

重点复核 R1−R0、R2−R1、R3−R1、R4−R2、R4−R3、R2−R5。若某项仅在部分种子改善，故事线应如实呈现，不能只保留支持预期结果的运行。
