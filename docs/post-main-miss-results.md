# MISS 双路 CTR 适配：三种子结果

在既定公共协议下，协同＋内容双路没有表现出稳定的 GAUC 优势。相对相同结构的内容分段对照，三个种子的 GAUC 点估计均为负，其中一个区间完全低于零，两个跨零；AUC 则三个种子均更高。参数共享的敏感性结果同样没有形成跨种子一致的收益。

本实验是主测试已查看后的验证集补充，不是原始 MISS 树召回系统复现。配置、预算和论文歧义的处理在[固定协议](post-main-miss-protocol.md)中说明。

## 解释与边界

九次运行均完整训练 3,052,475 条样本、验证 768,773 条样本，通过固定配置、源文件、数据指纹、预测行对齐、资源门槛和检查点重载校验。每路 25 条，总处理预算 50；双路可能有交集，内容分段对照不重复取位置，实际去重覆盖与交集保留在报告中。

三种子都出现 AUC 与 GAUC 方向不同的主比较，不能只选择 AUC 宣称双路整体更好。参数共享同时改变约束和参数量；敏感性实验不用于选择论文“正确版本”。所有六组区间为 2,000 次用户级配对 bootstrap，条件于各次已训练模型，未做多重比较校正，也不能将跨零解释为等效。

本结果不识别原始 MISS 索引树、MMoE 或线上召回收益，不直接与不同聚合结构的 MUSE 主表作单因素归因。当前证据支持保留简单内容检索作为有竞争力的对照，不能推广为所有双路模型无效。
