# R0–R5 核心效果对照

## 实验矩阵

各组统一使用阶段 2 的 `MUSEModel`，短历史分支和公共预测网络保持一致。

|配置|GSU|长历史 ID 路径|长历史统计路径|
|---|---|---|---|
|R0|最近 K 条|TA|关闭|
|R1|内容余弦 Top-K|TA|关闭|
|R2|内容余弦 Top-K|TA|可学习 SimTier|
|R3|内容余弦 Top-K|SA-TA|关闭|
|R4|内容余弦 Top-K|SA-TA|可学习 SimTier|
|R5|内容余弦 Top-K|关闭|可学习 SimTier|

TA 表示目标注意力，SA-TA 表示语义感知目标注意力。R0 仍有独立短分支与长分支，不能当作单独的 DIN 基线。

R5 不查找被检索长历史的 ID embedding，不计算长历史注意力，以零向量占据公共 MLP 对应位置；长历史注意力和 V 参数冻结并从优化器排除。公共短分支及目标/用户特征保留，因此 R5 不是全模型内容-only。专项测试验证：修改短分支之外的历史 ID 不改变 R5 输出。

## 数据与训练

与前序 CIKM 项目共享 1% 用户子集、特征存储版本和评估定义。每组训练 609,902 条曝光，完整验证 151,947 条曝光，seed 42、L=200、K=50、短分支 50、batch 32、训练一轮。embedding 宽度 16，SparseAdam 与 AdamW 学习率均为 0.001，权重衰减为零。

各组从初始化开始，训练样本顺序一致；保留最后不足 batch 的记录。验证按完整记录汇总，不平均 batch 指标。GAUC 的用户分组使用原用户行标识，避免将 OOV 用户合并。测试集不参与训练、调参或本轮评估。

```powershell
python scripts/run_core_study.py --store <shared-feature-store> --output-dir <fresh-study-directory>
```

队列按 R0 至 R5 串行执行；任一任务失败时停止后续任务。`status.json`、独立日志和各任务 `report.json` 区分运行状态。单项运行可使用 `scripts/train_muse.py` 和对应 `configs/rN.json`。

每项保存配置、代码/数据校验和、完整验证预测、模型参数、资源统计以及重载误差。检查点不含优化器状态，不用于精确断点续训；中断任务使用新目录重新开始。

## 分析计划与边界

- R1 对 R0：比较完整检索策略，包括阶段 1 定义的缺失内容处理。
- R2 对 R1、R4 对 R3：分别检查普通/语义注意力下统计分支的贡献。
- R3 对 R1、R4 对 R2：分别检查无/有统计分支时的语义融合贡献。
- R2 对 R5：在保持检索与统计分支时检查长历史 ID 路径贡献。

配对比较核对全部标签与行标识，报告 AUC、GAUC、LogLoss 和用户 bootstrap 区间。单种子区间不能代替多种子验证，也不能以方法点估计排序推断稳定优劣。
