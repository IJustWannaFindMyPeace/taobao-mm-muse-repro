## 最终检查点行为

固定抽取 1024 个等间隔验证曝光位置，读取最终权重，不更新模型。对多模态表示有效的历史，保持 ID 分数不变时，融合评分对语义相似度的斜率是 `gamma[1] + gamma[2] * ID_score`。该斜率可以为负；不能仅凭一个系数为负判断整体排序。

|种子|负斜率比例|与多模态表示 Top-50 重叠率|融合选中平均多模态余弦|多模态表示对照平均余弦|
|---|---:|---:|---:|---:|
|42|0.00%|80.58%|0.340710|0.350426|
|2026|100.00%|0.37%|-0.097385|0.350426|
|3407|0.00%|74.68%|0.335666|0.350426|

2026 的最终检索明显偏向语义相似度较低的行为，与其 GAUC 下降相一致。诊断描述最终模型的评分行为，不建立训练过程的因果解释，也不证明给融合系数加正约束一定有效。另两个种子 AUC/LogLoss 有改善而 GAUC 不占优，不能将结果简化为全指标一致退步。

六次完整训练均通过行数、源文件、配置、预测对齐及重载检查。区间采用每种子 2,000 次用户级配对 bootstrap，条件于已训练模型，无多重校正。原结果保留；未根据诊断调整权重、补选种子或重写冻结测试表。缺失目标多模态表示的回退样本不计入上述检索行为统计。

全部指标、指纹、权重与诊断样本位置见[机器可读报告](../reports/post-main-g3-validation.json)。G1 多模态可学习评分仍是独立缺口，不能用本结果替代。
