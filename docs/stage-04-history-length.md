# 历史长度端点对照：L=200 与 L=1000

> 文档性质：阶段记录／历史协议。本文中的规模、配置、验证结果及待办状态属于记录时点；当前结果以[主测试](final-test-results.md)、[补充测试](supplementary-test-results.md)和[覆盖说明](current-reproduction-status.md)为准。

## 研究问题

首轮 L=200 实验未确认多模态检索相对近期历史的稳定 GAUC 增益。本阶段增加候选历史范围，分别观察 R1（多模态检索 + TA）和 R4（多模态检索 + SA-TA + SimTier）。不能通过仅增加完整模型的历史长度来归因增强 ESU 的效果。

## 控制变量

新配置为 `r1-l1000.json`、`r4-l1000.json`。与各自 L=200 配置相比，仅 `history_length` 从 200 改为 1000，实验标签相应更新；自动核对配置差异通过。

以下保持一致：1% 用户子集、训练与验证记录、完整历史构建的训练词表、固定 SCL 表、seed 42、K=50、短分支最近 50 条、embedding 宽度 16、batch 32、优化器及学习率、单轮训练、训练样本次序和缺失多模态表示协议。

增加的是 GSU 候选范围，ESU 仍处理最多 50 条历史。不同候选范围会改变检索结果及其后续训练梯度，这是研究对象；不扩充数据行数，也不重新定义词表。

## 运行入口

```powershell
python scripts/run_core_study.py --store <shared-feature-store> --output-dir <fresh-length-study> --configs r1-l1000 r4-l1000
```

队列先训练 R1，再训练 R4；每组从初始化开始，串行运行并保留独立日志、预测和模型。失败时不启动后续任务。沿用统一训练入口的完整验证、有限损失/梯度与保存重载检查。

## 预定分析

- R1 L=1000 对 R1 L=200：普通 ESU 下扩大候选历史范围的作用。
- R4 L=1000 对 R4 L=200：增强 ESU 下扩大候选历史范围的作用。
- 同为 L=1000 的 R4 对 R1：更长候选历史下增强 ESU 的作用。

分析核对完整预测记录与公共配置，报告 AUC、GAUC、LogLoss、用户配对 bootstrap 区间以及训练时长和显存。若比较两条曲线的增量差，须作为额外交互对照计算，不能以某一组区间跨零、另一组不跨零直接证明两组增量不同。

## 当前状态与边界

15 项单元测试通过；两项完整训练与来源核验已完成，结果见下文。此前 L=1000 的 20 步资源检查通过，但不能替代本次全轮稳定性检查。

本阶段仅比较 200 与 1000 两个端点，未完成 50/200/500/1000 的完整长度扫描。仍是固定 1% 子集和单随机种子，不确定最大数据规模；多种子、低频分组、独立基线及保留测试集评估待后续完成。

## 全轮结果：固定 1% 子集与 seed 42

|模型|L|AUC|GAUC|LogLoss|训练分钟|
|---|---:|---:|---:|---:|---:|
|R1|200|0.593715|0.559443|0.394643|7.25|
|R1|1000|0.593768|0.561485|0.396383|10.94|
|R4|200|0.607157|0.581428|0.392752|8.08|
|R4|1000|0.608381|0.581905|0.392966|10.77|

两项 L=1000 训练各处理 609,902 条记录，完整验证 151,947 条记录，参数更新与重载核验通过，重载误差均为零。训练合计约 21.71 分钟，不含验证与保存；两组峰值分配显存约 2,874.8 MiB（2.81 GiB）。

已核验相同模型的两个长度使用同一份实现校验和和特征存储版本，配置仅历史长度和实验标签不同。当前 1% 词表下，L=1000 全轮训练可运行；这并不意味着更大词表、数据量或全部实验预算已确定。

|候选减基准|GAUC 差值|95% 用户 bootstrap 区间|

|[r1-l1000-vs-l200](../reports/r1-l1000-vs-l200.json)|+0.002042|[-0.002298, +0.006457]|
|[r4-l1000-vs-l200](../reports/r4-l1000-vs-l200.json)|+0.000477|[-0.003522, +0.004539]|
|[r4-vs-r1-l1000](../reports/r4-vs-r1-l1000.json)|+0.020420|[+0.016052, +0.024690]|

两种模型扩大候选历史范围后的 GAUC 区间均跨零，LogLoss 点估计均变差；本轮没有确认更长历史稳定改善效果。同为 L=1000 时，R4 相对 R1 的 AUC/GAUC 更高、LogLoss 更低，GAUC 增量区间高于零，为增强 ESU 在当前设置下的作用提供初步证据。

区间由 2,000 次用户配对重采样产生，仅条件于当前模型和子集；未进行多重比较校正，不包含种子或子集选择的不确定性。不能将这些结果解释为历史长度没有价值，也不能推断收益差异由某一未测因素造成。

当前实验已经核验 L=1000 的全轮可运行性。下一步需结合完整实验数量、数据预处理与训练预算确定共同数据规模，补充多种子和低频诊断；不会为了获得预期排名反复选择长度。测试集继续保留。
