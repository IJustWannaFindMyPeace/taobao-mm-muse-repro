# 阶段 5：5% 数据上的核心消融

## 共同实验基础

本轮与多模态融合项目使用同一份 5% 特征存储、训练/验证划分和固定多模态向量。训练曝光 3,052,475 条，验证曝光 768,773 条；不对保留测试集进行模型评估。

存储 manifest SHA256：`7dd761c48f61b3ae219922f8387f6026eb6eb011ef6ef8050bb1472a52593f59`。准备与资源核验见[共享数据报告](https://github.com/IJustWannaFindMyPeace/taobao-mm-content-integration/blob/main/docs/stage-16-scale-preparation.md)。

模型保持阶段 3 的实现适配：历史长度 200、检索 K=50、短历史 50、embedding 宽度 16、batch size 32、seed 42，每组完整训练一轮。两类优化器学习率均为 0.001，weight decay 为 0。

## 痛点与消融关系

|配置|检索及长历史处理|主要比较|
|---|---|---|
|R0|最近行为 + ID 注意力|检索参照|
|R1|多模态余弦 Top-K + ID 注意力|R1−R0：目标相关筛选|
|R2|R1 + SimTier|R2−R1：兴趣分布统计|
|R3|R1 + SA-TA|R3−R1：语义与 ID 注意力融合|
|R4|R1 + SimTier + SA-TA|R4−R2、R4−R3：组合的额外贡献|
|R5|多模态表示 Top-K + SimTier，关闭长历史 ID 聚合|R2−R5：长历史 ID 聚合的额外贡献|

GSU（General Search Unit）负责从完整历史中筛选行为，ESU（Exact Search Unit）负责对选中行为进行精细建模。SA-TA（Semantic-Aware Target Attention）为语义感知目标注意力。R5 仍保留用户/目标 ID 和短历史 ID 分支，不是全模型的多模态表示单模态对照。所有模块的具体公式与掩码适配沿用阶段 2、3。

CIKM 的 C0 与本项目 R0 并非只差一个检索开关；两个骨干的历史处理与 V 投影存在差异。因此跨项目数值可展示共同数据上的系统表现，但检索和模块贡献必须用本表内部的控制变量比较。两个项目的 SimTier 实现也分别保留其定义，不作同名等价处理。

## 故事线中的证据边界

- **检索痛点：**长度 200 下，R1 相对 R0 的收益区间跨零，尚未确认多模态检索本身的可靠优势；不能将 ESU 增益归为检索增益。
- **兴趣统计：**R2−R1 与 R4−R3 区间均高于零，支持本次运行中 SimTier 的增益。
- **语义融合：**R3−R1 区间高于零，支持 SA-TA 单独接入的增益；R4−R2 区间跨零，尚未确认加入统计分支后的额外收益。
- **ID 聚合：**R2−R5 区间跨零，当前尚未确认长历史 ID 聚合在该统计分支上的额外贡献；这不等于 ID 信息整体无效。

R4 的 GAUC 点估计最高，R2 的 LogLoss 更低，不能表述为完整模型全面胜出。所有区间以固定训练模型和验证人群为条件，不包含训练随机性、子集选择及模型选择的不确定性，六个区间未做多重比较校正。单种子验证结果不能代替其他随机种子或保留测试集证据。

本轮固定长度 200 做核心模块消融。5% 数据的 R1/R4 长度 1000 全轮对照及审计已完成，结果见[阶段 6](stage-06-five-percent-history-length.md)；此前长度 1000 的资源探测不作为效果结果。其他种子及补充基线仍待后续运行。
