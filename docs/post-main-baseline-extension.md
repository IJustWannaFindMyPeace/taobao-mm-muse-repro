# 主实验完成后的基线补充阶段

本阶段在已查看第一轮测试结果后启动，独立于原 54 模型冻结实验。原模型、超参数和主表不改写。新增模型先在既定训练/验证协议下实现与核验；后续如评估原测试集，应明确它已被研究者查看，不能称为新盲测或原预注册比较。

## 已核对的来源差异

|方法|来源中的关键结构|本地补充必须处理的差异|
|---|---|---|
|DIN|原论文以局部激活网络生成目标相关权重，并明确不使用 softmax 归一化|现有点积 softmax 注意力不能直接改名为原始 DIN。短历史公共主干适配与原始 DIN 机制实现应分别命名|
|MUSE 参考代码的 DIN 分支|已检查归档中通过 method=din 关闭长历史输出；其注意力、短历史特征及上层网络有独立实现|原始 DIN 论文、参考代码分支与公共主干对照是三个不同实现口径，不能混写为完全等价|
|TWIN|GSU 与 ESU 共享相关性计算；原文还拆分商品固有特征与用户交叉特征，并设计缓存|公开输入缺少原文的完整交叉行为特征。必须明确可实现的分支、共享参数与检索/聚合一致性，不以独立未训练 MLP 代替|
|MISS|原方法含多模态索引树、协同与内容双路检索；§4.2 对两路注意力是否共享参数存在相互矛盾的描述|MUSE 的 CTR 基线适配与 MISS 完整树召回系统不同；双路预算、聚合及参数共享须作为明确的实现选择，不能把两路余弦相加叫作 MISS|

本地参考归档 `MUSE-main` 含 DIN、SIM-hard、SIM-soft 配置及统一模型，未找到 TWIN/MISS 的独立实现；这仅描述已检查的归档，不推断所有版本的上游仓库都没有实现。

## 固定的推进次序

1. 复用冻结预测补训练曝光频次的测试分组，保持原六组边界。报告为事后描述性分析，不按结果调整分组。
2. MAKE 训练策略追加 seed=2026/3407，保留原随机/预训练 × 冻结/联合设计，并检查 ID 多轮曲线；沿用现有预训练检查点选择规则，先只评估验证集。
3. 明确 DIN 的论文机制版与公共主干短历史对照，再编写实现和参数/梯度测试；不得用现有近期历史两分支模型顶替原始 DIN。
4. 完成 TWIN、MISS 结构规格与公开输入映射，解决共享评分、两路候选预算及缺失处理后才开始训练。保持 batch=256 和共同数据，不先通过缩小 batch 勉强运行。

## 当前边界

DIN 与 TWIN 适配均已完成六次训练和三组配对统计，见 [DIN 结果](post-main-din-results.md)及 [TWIN 结果](post-main-twin-results.md)。MISS 九次完整训练与六项配对比较已完成，见[MISS 结果](post-main-miss-results.md)。数据仍为 5% 队列，本阶段不扩全量、不重新搜索学习率，也不将第一轮测试中的赢家作为新增模型的调参目标。
