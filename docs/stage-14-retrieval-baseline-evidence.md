# 阶段 14：内容检索相对类目与 ID 检索的证据

## 研究问题与控制变量

在相同的精细兴趣聚合模块下，内容向量能否比类目或 ID 向量选出更有用的历史？这一对照检验 MUSE 故事线中的历史检索环节，与近期 batch/学习率校准分开报告。

四种长历史方案均使用 L=1000、K=50、语义感知目标注意力与相似度统计，公共短历史分支、ID 维度、训练数据、seed=42、batch=32、学习率和单轮曝光预算一致。类目/ID 检索也使用内容增强的后续聚合，所以此处比较检索策略，不是“有内容与完全无内容”的对照。类目匹配不足 K 时不跨类目补齐，ID 与内容缺失回退规则见检索契约；这些规则属于被比较的策略。

仅短历史基线同时移除了长历史检索与聚合，不能把它与完整组合的差异全部归因于检索。

## 验证结果

|方法|AUC ↑|GAUC ↑|LogLoss ↓|
|---|---:|---:|---:|
|仅短历史公共注意力|0.600646|0.571284|0.390208|
|同类目检索 + 增强聚合|0.611898|0.585860|0.388146|
|商品/类目 ID 检索 + 增强聚合|0.611456|0.585813|0.388579|
|商品 ID 检索 + 增强聚合|0.610530|0.582626|0.388565|
|内容检索 + 增强聚合|0.618260|0.592314|0.387237|

|内容检索相对的基线|GAUC 差值|95% 用户配对区间|
|---|---:|---|
|仅短历史公共注意力|+0.021030|[0.018957, 0.023061]|
|同类目检索 + 增强聚合|+0.006454|[0.004812, 0.008043]|
|商品/类目 ID 检索 + 增强聚合|+0.006501|[0.004969, 0.008016]|
|商品 ID 检索 + 增强聚合|+0.009688|[0.008012, 0.011430]|

在该固定种子与验证队列上，内容检索的三个整体指标均优于其他检索策略，GAUC 配对区间均高于零。这为内容检索的作用提供直接证据，但不足以确认跨训练种子稳定性。

## 核验与局限

五组运行均完整训练 3,052,475 条曝光，验证 768,773 条记录。审计逐行核对源行、标签、用户，重算指标，核对训练步数、配置快照和公共模型依赖摘要；检查点存在且原训练报告重载误差为零，本次未重新加载权重。新增基线源码摘要与运行记录一致。训练入口的资源监测差异不改变被核验的公共模型依赖。

配对区间使用 2000 次用户 bootstrap，条件于固定模型与验证人群；四次比较未做多重校正，也不测量训练随机性。所有结果来自既有 batch=32 协议，不能混入新 batch/学习率运行后称为单变量方法提升。保留测试集未评估。

这些是公共主干上的适配基线，不是原始 DIN、SIM 完整实现。尤其短历史基线使用公共注意力；类目与 ID 检索使用增强聚合。公开 1000 条历史上的结果不能推广为工业十万历史证据。后续在冻结训练方案后补齐关键基线的多种子，而非仅凭本次排序宣布最终优胜。
